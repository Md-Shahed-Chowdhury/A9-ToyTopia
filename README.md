# Project name: ToyTopia
## Purpose: To give better and clean experience for buying toys
live URL: https://toytopia123.netlify.app/
---
### Key Features:
- Has google and email authentication.
- Has forget password feature
- Has profile update feature
- Can see toys of several events
- Can see all toys at a time
- Can try toys
